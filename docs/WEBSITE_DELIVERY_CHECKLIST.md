# Webサイト制作チェックリスト（tsukise-an）

最終更新: 2026-02-22

## 0. 使い方
- リリース前だけでなく、各フェーズ開始時にも見直す。
- すべての項目を一度に埋めず、`未着手 -> 進行中 -> 完了` で運用する。
- Issue管理する場合は、本チェックリストの大項目を親Issue、項目を子Issueへ分解する。

## 1. 要件・計画
- [ ] 目的/KPI（CV、離脱率、問い合わせ数）を定義した
- [ ] ターゲットユーザーと主要ユースケースを定義した
- [ ] スコープ内/外を明文化した
- [ ] マイルストーンと担当を決めた
- [ ] リスク（外部連携、素材未確定、法務）を棚卸しした

## 2. 情報設計・導線
- [ ] サイトマップ（ページ一覧）を確定した
- [ ] URL設計を確定した
- [ ] グローバルナビ/フッターナビの導線を定義した
- [ ] CTA（予約/問い合わせ）到達フローを定義した
- [ ] 404/500時の戻り導線を定義した

## 3. コンテンツ
- [ ] 原稿（見出し/本文/注釈）を確定した
- [ ] 画像/動画/OGP素材を準備した
- [ ] 電話番号/メール/SNS/外部リンクを確定した
- [ ] 法務ページ文言（privacy/legal）を確定した
- [ ] ダミー値と本番値の置換箇所を一覧化した

## 4. デザイン
- [ ] PC/SPの主要画面デザインが確定した
- [ ] タイポ/色/余白/ボタン仕様を定義した
- [ ] デザイン差分（Pencilとの差分）を記録した
- [ ] 状態設計（hover/focus/disabled/error/loading）を定義した

## 5. 実装（フロント）
- [ ] ページ構成をApp Routerで実装した
- [ ] 共通レイアウト（Header/Footer/CTA）を共通化した
- [ ] 画像最適化（next/image, sizes, priority）を適用した
- [ ] コンポーネント分割と命名ルールを適用した
- [ ] 主要コンポーネントにStory/サンプルを用意した

## 6. 実装（バックエンド連携）
- [ ] 環境変数の必須/任意を定義した
- [ ] Cal.com連携を実装した（`/reservation`）
- [ ] Web3Forms連携を実装した（`/contact`）
- [ ] microCMS連携を実装した（`/news`, `/news/[slug]`, `/faq`）
- [ ] 失敗時のユーザー向けメッセージを実装した
- [ ] ログ/監視に必要な情報を出力した

## 7. 品質（テスト）
- [ ] 単体テスト（重要ロジック）を実装した
- [ ] E2Eテスト（主要導線）を実装した
- [ ] リンクチェックを実行した（`npm run check:links`）
- [ ] フォーム送信の正常系/異常系を確認した
- [ ] 主要ブラウザ（Chrome/Safari）で表示確認した
- [ ] モバイル（iOS/Android相当）で表示確認した

## 8. SEO・アクセシビリティ
- [ ] `title`/`description`/OGPを設定した
- [ ] `sitemap`/`robots` を用意した
- [ ] 構造化データ（FAQ/Articleなど）を設定した
- [ ] 見出し階層（h1-h2-h3）を確認した
- [ ] alt/aria/キーボード操作を確認した
- [ ] コントラスト比とフォーカス可視性を確認した

## 9. セキュリティ・運用
- [ ] 秘密情報をコードに直書きしていない
- [ ] `.env.example` を更新した
- [ ] リリース手順/ロールバック手順を記載した
- [ ] 障害時Runbookを整備した
- [ ] 公開後の監視/ログ確認手順を整備した

## 10. リリース判定
- [ ] 重大バグ（P0/P1）がクローズ済み
- [ ] 主要KPIの計測設定が完了
- [ ] ステークホルダーレビュー完了
- [ ] 公開Go判断の記録を残した
